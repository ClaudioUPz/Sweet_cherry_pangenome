# Step 7: INDEL extraction and analysis from the pangenome

This step describes how INDELs were extracted from MiniCactus VCF outputs and converted into per-sample tabular format for downstream analysis.

---

## Overview

The workflow includes:

1. Extracting INDELs from VCF files
2. Exporting INDELs into long-format CSV tables per chromosome

---

## Requirements

- bcftools

---

## Step 1: Extract INDELs from VCF files

INDELs were extracted from chromosome-specific VCF files generated by MiniCactus.

### Script

Save as `extract_indels.sh`:

```bash
#!/bin/bash
#SBATCH --job-name=indels_extract
#SBATCH --time=02:00:00
#SBATCH -o indels_extract.%N.%j.out
#SBATCH -e indels_extract.%N.%j.err
#SBATCH --mem=8G
#SBATCH --cpus-per-task=1

set -euo pipefail

BASE="/path/to/project"
CHRS="${CHRS:-1 2 3 4 5 6 7 8}"
MODE="${MODE:-auto}"

module load bcftools 2>/dev/null || true
command -v bcftools >/dev/null || { echo "ERROR: bcftools not found in PATH."; exit 1; }

echo "MODE=${MODE}; chromosomes: ${CHRS}"
echo "BASE=${BASE}"

for chr in ${CHRS}; do
  echo "Processing chr${chr}"

  final_vcf="${BASE}/5.pangenome/chr${chr}/backup/output/chr${chr}_run.vcf.gz"
  raw_vcf="${BASE}/5.pangenome/chr${chr}/backup/output/chr${chr}_run.raw.vcf.gz"

  case "${MODE}" in
    final)
      SRC="${final_vcf}"
      [[ -s "${SRC}" ]] || { echo "ERROR: missing ${SRC}"; exit 1; }
      ;;
    raw)
      SRC="${raw_vcf}"
      [[ -s "${SRC}" ]] || { echo "ERROR: missing ${SRC}"; exit 1; }
      ;;
    auto|*)
      if [[ -s "${final_vcf}" ]]; then
        SRC="${final_vcf}"
      elif [[ -s "${raw_vcf}" ]]; then
        SRC="${raw_vcf}"
        echo "WARNING: using RAW VCF for chr${chr}"
      else
        echo "ERROR: no VCF found for chr${chr}"
        exit 1
      fi
      ;;
  esac

  outdir="${BASE}/7.INDEL/chr${chr}"
  mkdir -p "${outdir}"

  outvcf="${outdir}/indels_chr${chr}.vcf.gz"

  bcftools view -v indels -Oz -o "${outvcf}" "${SRC}"
  bcftools index -f -t "${outvcf}"

  bcftools query -l "${outvcf}" > "${outdir}/samples.txt"

  nvars=$(bcftools view -H "${outvcf}" | wc -l || echo 0)
  nsamp=$(wc -l < "${outdir}/samples.txt" || echo 0)

  echo "chr${chr}: ${nvars} INDELs, ${nsamp} samples"
done

echo "INDEL extraction completed."
Usage
sbatch extract_indels.sh
Output

indels_chrX.vcf.gz – compressed INDEL VCF per chromosome

indels_chrX.vcf.gz.tbi – index file

samples.txt – list of samples per chromosome

Step 2: Export INDELs to CSV format

INDELs were converted into long-format CSV tables, where each row corresponds to a variant carried by a sample.

Script

Save as export_indels_csv.sh:

#!/bin/bash
#SBATCH --job-name=indels_csv
#SBATCH --time=02:00:00
#SBATCH -o indels_csv.%N.%j.out
#SBATCH -e indels_csv.%N.%j.err
#SBATCH --mem=8G
#SBATCH --cpus-per-task=1

set -euo pipefail

BASE="/path/to/project"
CHRS="${CHRS:-1 2 3 4 5 6 7 8}"

module load bcftools
command -v bcftools >/dev/null || { echo "ERROR: bcftools not found"; exit 1; }

for chr in ${CHRS}; do
  vcf="${BASE}/7.INDEL/chr${chr}/indels_chr${chr}.vcf.gz"
  out="${BASE}/7.INDEL/chr${chr}/indels_details_chr${chr}.csv"

  [[ -s "${vcf}" ]] || { echo "ERROR: missing ${vcf}"; exit 1; }

  echo "Processing chr${chr}"
  echo "CHROM,POS,REF,ALT,SAMPLE,GT" > "${out}"

  bcftools query -f '%CHROM\t%POS\t%REF\t%ALT[\t%SAMPLE\t%GT]\n' "${vcf}" \
  | awk -F'\t' '{
      CH=$1; POS=$2; REF=$3; ALT=$4;
      for(i=5;i<=NF;i+=2){
        S=$(i); GT=$(i+1);
        if(GT ~ /[1-9]/)
          printf "%s,%s,%s,%s,%s,%s\n", CH,POS,REF,ALT,S,GT;
      }
    }' >> "${out}"

  nl=$(wc -l < "${out}" || echo 0)
  echo "chr${chr}: ${nl} rows (including header)"
done

echo "CSV export completed."
Usage
sbatch export_indels_csv.sh
Output

indels_details_chrX.csv for each chromosome

Notes

Only variants with at least one alternative allele are retained.

Multi-allelic INDELs are included by default.

The output format is consistent with SNP analysis, enabling direct comparison.

Paths should be adapted to your local project structure.
