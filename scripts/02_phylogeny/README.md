# Step 2: Phylogenetic tree construction (k-mer distances with PanTools)

This step describes the construction of a phylogenetic tree based on k-mer distances using PanTools, followed by tree inference in R and visualization.

---

## Input data

All genome assemblies (FASTA format) must be preprocessed (header renaming and formatting) and stored in a directory (e.g., `genomes/`).

A text file listing the full paths to each genome FASTA file is required.

### Example: `genome_locations.txt`

```text
/home/curra/pangenome/4.phylogeny/genomes/Regina_hap1_renamed.fasta
/home/curra/pangenome/4.phylogeny/genomes/Regina_hap2_renamed.fasta
/home/curra/pangenome/4.phylogeny/genomes/Santina_hap1_renamed.fasta
/home/curra/pangenome/4.phylogeny/genomes/Santina_hap2_renamed.fasta
...
Step 1: Build pangenome database (PanTools)

PanTools v4.3.3 was used to construct the pangenome database.

SLURM job script
#!/bin/bash
#SBATCH --job-name=pangenome_build
#SBATCH --time=300:00:00
#SBATCH --cpus-per-task=48
#SBATCH --mem=700G
#SBATCH -o pangenome_build.%j.out
#SBATCH -e pangenome_build.%j.err

module load pantools
module load kmc

WORKDIR=/home/curra/pangenome/4.phylogeny
GENOMES=$WORKDIR/genome_locations.txt
DBDIR=/dev/shm/paviumdb
SCRATCH_DIR=/tmp/curra

mkdir -p "$SCRATCH_DIR"

pantools -Xmx700g -Xms700g build_pangenome \
  --kmer-size=21 \
  --threads=48 \
  --scratch-directory="$SCRATCH_DIR" \
  "$DBDIR" "$GENOMES"

if [ $? -eq 0 ]; then
  echo "PanTools completed successfully. Removing scratch directory..."
  rm -rf "$SCRATCH_DIR"
else
  echo "PanTools failed. Scratch directory retained for debugging."
fi

Step 3: Phylogenetic tree construction in R

The phylogenetic tree was constructed using the Neighbor-Joining method implemented in the ape package.

R script
library(ape)

input <- read.csv("genome_mash_distance.csv", sep = ",", header = TRUE)

genome_names <- readLines("genome_locations.txt")
genome_names <- gsub("_renamed", "", genome_names)
genome_names <- gsub("\\.fa$|\\.fasta$|\\.gz$", "", basename(genome_names))
genome_names <- gsub("\\.", "_", genome_names)

colnames(input)[-1] <- genome_names
input$Genomes <- genome_names

dataframe <- subset(input, select = -c(Genomes))
df.distance <- as.matrix(dataframe)
colnames(df.distance) <- rownames(df.distance) <- input[['Genomes']]

NJ_tree <- nj(df.distance)

write.tree(NJ_tree, file = "genome_kmer_distance.tree")

cat("\nK-mer distance tree written to: genome_kmer_distance.tree\n\n")
Output

genome_kmer_distance.tree (Newick format)

Step 4: Tree visualization

The resulting tree can be visualized and edited using tree visualization software such as Dendroscope.

Re-rooting the tree using the selected node
