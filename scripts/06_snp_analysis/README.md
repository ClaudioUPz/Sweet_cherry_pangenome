# Step 6: SNP extraction and analysis from the pangenome

This step describes how SNPs were extracted from MiniCactus VCF outputs, processed into tabular format, and summarized per genome/haplotype.

---

## Overview

The workflow includes:

1. Extracting SNPs from VCF files
2. Converting SNP data into per-sample long-format tables
3. Summarizing SNP counts per genome
4. Normalizing SNP counts by genome size
5. Generating plots

---

## Step 1: Extract SNPs from VCF files

SNPs were extracted from chromosome-specific VCF files generated by MiniCactus.

### Script

Save as `extract_snps.sh`:

```bash
#!/bin/bash
#SBATCH --job-name=snps_vcf
#SBATCH --cpus-per-task=2
#SBATCH --mem=8G
#SBATCH --time=02:00:00
#SBATCH -o logs/snp_vcf.%j.out
#SBATCH -e logs/snp_vcf.%j.err

set -euo pipefail

module load bcftools

BASE="/home/curra/pangenome"
IN_DIR="$BASE/5.pangenome"
OUT_DIR="$BASE/6.SNP"

mkdir -p "$OUT_DIR" logs

for chr in {1..8}; do
  in_vcf="$IN_DIR/chr${chr}/backup/output/chr${chr}_run.vcf.gz"
  if [[ ! -f "$in_vcf" ]]; then
    echo "ERROR: Missing $in_vcf"; exit 1
  fi

  out_chr_dir="$OUT_DIR/chr${chr}"
  mkdir -p "$out_chr_dir"

  bcftools view -v snps -Oz -o "$out_chr_dir/snps_chr${chr}.vcf.gz" "$in_vcf"
  bcftools index -t "$out_chr_dir/snps_chr${chr}.vcf.gz"

  echo "Finished chr${chr}: $out_chr_dir/snps_chr${chr}.vcf.gz"
done

echo "All SNP VCFs generated."
Usage
sbatch extract_snps.sh
Step 2: Export SNPs to CSV format

SNPs were exported into long-format CSV files, one per chromosome.

Each row corresponds to:

one SNP

one sample carrying the alternative allele

Script

Save as export_snps_csv.sh:

#!/bin/bash
#SBATCH --job-name=snps_csv
#SBATCH --cpus-per-task=2
#SBATCH --mem=8G
#SBATCH --time=02:00:00
#SBATCH -o logs/snp_csv.%j.out
#SBATCH -e logs/snp_csv.%j.err

set -euo pipefail
module load bcftools

BASE="/home/curra/pangenome"
SNP_DIR="$BASE/6.SNP"

mkdir -p logs

for chr in {1..8}; do
  vcf="$SNP_DIR/chr${chr}/snps_chr${chr}.vcf.gz"
  [[ -f "$vcf" ]] || { echo "Missing $vcf"; exit 1; }

  outdir="$SNP_DIR/chr${chr}"
  names_file="$outdir/samples.txt"
  bcftools query -l "$vcf" > "$names_file"

  tmp="$outdir/_gt.tsv"

  bcftools query -f '%CHROM\t%POS\t%REF\t%ALT[\t%GT]\n' "$vcf" > "$tmp"

  awk -v OFS=',' -v names="$names_file" '
    BEGIN{
      i=1; while((getline n < names)>0){ sample[i]=n; i++ } close(names);
      print "CHROM","POS","REF","ALT","SAMPLE","GT";
    }
    {
      for(j=5;j<=NF;j++){
        gt=$j
        if (gt ~ /[1-9]/) {
          idx=j-4; s=sample[idx];
          print $1,$2,$3,$4,s,gt;
        }
      }
    }' "$tmp" > "$outdir/snps_details_chr${chr}.csv"

  rm -f "$tmp"
  echo "Generated $outdir/snps_details_chr${chr}.csv"
done

echo "All SNP CSV files generated."
Output

snps_details_chrX.csv for each chromosome

Notes

SNP counts are based on presence of alternative alleles (non-reference genotypes).

Normalization is performed using total sequence length per sample and chromosome.

This analysis reflects variation within the graph-based pangenome rather than a single linear reference.
